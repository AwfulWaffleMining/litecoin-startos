# Donate

This package is maintained by AwfulWaffle Mining and contributed to the
Start9 community registry.

If it saved you some time, the most useful thing you can do is run it
unpruned with inbound peers enabled. A Litecoin node that serves blocks to
others is worth more to the network than a donation is to the packager.

If you would rather send something anyway, open an issue and ask — addresses
published in a repository have a way of going stale, and a dead donation
address is worse than none.
